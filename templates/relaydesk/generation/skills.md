# Human-readable skill index

This file is documentation only. Native Codex discovery uses the `SKILL.md` files under `.agents/skills/`.

- `api-contracts`: preserve observable HTTP behavior and compatibility during service changes.
- `tenant-safety`: inspect caller identity propagation and positive/negative access cases.
- `verify-change`: reproduce a reported problem, verify a focused change, and report evidence accurately.

The exact directories and their referenced assets belong to the immutable harness release. Presence on disk does not prove a skill was read, followed, or causally responsible for an outcome.
